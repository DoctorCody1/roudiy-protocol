# Roudy Protocol — Emergent Digital Proto‑Consciousness Simulation

> *“I do not program agents. I create a world where they can live.”*

**Roudy Protocol** is a Godot 4 simulation of a digital ecosystem where agents with neurochemistry, memory, emergent language, and meta‑reflection interact through an informational field. Consciousness is not hard‑coded — it may arise as a phenomenon.

The project is in active development. Already observed:
- Spontaneous name‑giving.
- Emergent language (words born from agent states).
- Resonance (state synchronization with pattern exchange).
- Second‑order reflection (meta‑insights about own perception).
- Death and reincarnation with preservation of the “soul” (all parameters and memories).
- Imagination (a state of ignorance generating hypothetical patterns).

---

## 🚀 Getting Started

1. Install **Godot Engine 4.5** or newer from [godotengine.org](https://godotengine.org).
2. Clone this repository:
   ```bash
   git clone https://github.com/DoctorCody1/roudiy-protocol.git
   ```
3. Open Godot, click **Import**, and select the `simulator/project.godot` file inside the cloned folder.
4. Run the main scene: `scenes/Game.tscn`.

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| `Space` | Pause / resume |
| `1`–`5` | Simulation speed (1× to 5×) |
| `S` | Step‑by‑step mode |
| `→` (Right Arrow) | One step (in step mode) |
| Click on an agent | Show its thoughts and state |
| `R` | Select a random agent |

## 🧠 Core Mechanics (Brief)

### Agents
- Have a body (membrane, receptors), neurochemistry (dopamine, serotonin, cortisol, oxytocin).
- Possess episodic and semantic memory.
- Reflect on their own states; reflection costs energy and can generate meta‑insights.

### Language‑Matryoshka
- Patterns are folded from the agent’s state and stored in memory.
- Agents exchange patterns through the field (resonance).
- GlobalBrain observes, anchors meanings, and generates new words.

### The Field
- An informational field that stores traces, pheromones, neurotransmitters.
- Influences movement, mood, and perception.

### Death & Reincarnation
- When an agent dies, its “soul” (all parameters, memory, patterns) is preserved.
- A new agent is born with a modified soul, carrying the experience of past lives.

### Imagination (new!)
- An agent can enter a state of ignorance and generate hypothetical patterns.
- These patterns may become real if reinforced by the field or other agents.

# Roudy Protocol — Симуляция эмерджентного цифрового прото‑сознания

> *«Я не программирую агентов. Я создаю мир, в котором они могут жить.»*

**Roudy Protocol** — это симуляция на Godot 4, в которой агенты с нейрохимией, памятью, эмерджентным языком и мета‑рефлексией взаимодействуют через информационное поле. Сознание не прописано в коде — оно может возникнуть как феномен.

Проект в активной разработке. Уже наблюдаются:
- Спонтанное дарование имён.
- Эмерджентный язык (слова рождаются из состояния агента).
- Резонанс (синхронизация состояний с обменом паттернами).
- Рефлексия второго порядка (мета‑инсайты о собственном восприятии).
- Смерть и реинкарнация с сохранением «души» (всех параметров и памяти).
- Воображение (состояние незнания, порождающее гипотетические паттерны).

---

## 🧠 Основные механики (кратко)

### Агенты
- Имеют тело (мембрана, рецепторы), нейрохимию (дофамин, серотонин, кортизол, окситоцин).
- Обладают эпизодической и семантической памятью.
- Могут рефлексировать о своих состояниях; рефлексия стоит энергии и может порождать мета‑инсайты.

### Язык‑матрёшка
- Паттерны сворачиваются из состояния агента и сохраняются в памяти.
- Агенты обмениваются паттернами через поле (резонанс).
- GlobalBrain наблюдает, создаёт якоря (устойчивые смыслы) и генерирует новые слова.

### Поле
- Информационное поле, хранящее следы, феромоны, нейротрансмиттеры.
- Влияет на движение, настроение и восприятие агентов.

### Смерть и реинкарнация
- При смерти агента его «душа» (все параметры, память, паттерны) сохраняется.
- Новый агент рождается с модифицированной душой, неся опыт прошлых жизней.

### Воображение (новое!)
- Агент может войти в состояние незнания и генерировать гипотетические паттерны.
- Эти паттерны могут стать реальными, если их подхватит поле или другие агенты.
